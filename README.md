# Content_Verst_Free

> **Управление контентом для социальных сетей** — простой и удобный инструмент для планирования и публикации постов.

---

## 📌 Описание

Приложение позволяет:
- Создавать и редактировать посты,
- Управлять медиафайлами,
- Настраивать видимость полей,
- Планировать публикации,
- Работать с базой данных Access (.accdb).

---

## ⚙️ Технические детали

- **Язык**: C++/CLI (Windows Forms)
- **База данных**: Microsoft Access (.accdb)
- **Зависимости**: 
  - [Microsoft Access Database Engine 2016 Redistributable](https://www.microsoft.com/en-us/download/details.aspx?id=54920) (требуется для работы)
- **Архитектура**: x64 (рекомендуется)

---

## 📦 Установка

1. Скачайте установщик:  
   [`Content_Verst_Free_Installer.exe`](https://github.com/Supercarplay/Content_Verst_Free_Versions/releases/latest)
2. Запустите установщик.
3. Установщик автоматически установит драйвер Access Database Engine (если он не установлен).
4. После установки приложение запустится автоматически.

> 💡 Если вы хотите запустить без установщика — скопируйте папку `Program\x64\Release\` и убедитесь, что рядом лежит файл `Database.accdb`.


---

## ⚠️ Важно

- При первом запуске создается файл `settings.ini` в папке приложения.
- База данных `Database.accdb` должна находиться в той же папке, что и `.exe`.
- Для работы требуется установленный **Access Database Engine** (входит в установщик).
